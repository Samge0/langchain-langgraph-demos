Pedagogy

为什么是这个顺序——对应面试考察体系

不是 API 文档的目录顺序，而是面试官确认你「懂底层而不只是会调包」的考察顺序。

L01–L03 · MODEL I/O

先证明你懂底层

消息模型、结构化输出原理——面试官确认你理解框架下面的东西，而不是只会 import。

L04 · ATOMIC

Agent 的原子能力

Tool Calling 本质是「模型输出 JSON → 你执行 → 结果回填 messages」。面试必考「Agent 的执行循环是什么」，这一课让你能手写它——create_agent 只是把这个循环自动化。

L05–L06 · FRAMEWORK

用框架的正确姿势

create_agent 的 AgentLoop、MCP 工具生态——2025+ 行业标准的工具接入协议。

L07–L09 · CORE

LangGraph 三大高频考点

状态图 = 可控的 Agent 编排；Checkpointer = 记忆；interrupt = 人机协同。这三点是 Agent 岗面试的最高频考点。

L10–L12 · PRODUCTION

生产化收尾

上下文工程（token 预算、Summarization 压缩）→ RAG 全链路优化（切分、混合检索、重排、查询改写）→ 多智能体任务分解。至此你能在面试里完整回答「一个 Agent 系统从原型到上线要经过什么」。
